# tauri-vue-template

[简体中文](./README.zh-CN.md)

This repository maintains multiple branches for Tauri 2 + Vue 3 template variants.

The `main` branch is only a repository entry point and branch directory. It does not contain the full template source code. Choose one of the template branches below:

| Branch | Description | Use case |
| --- | --- | --- |
| `standalone` | Single-app Tauri + Vue template | A straightforward starting point for desktop and mobile apps |
| `turborepo` | Turborepo / monorepo template | Multi-app, multi-package, and team-oriented setups |

## Usage

Clone the standalone template:

```bash
git clone -b standalone https://github.com/zzjtnb/tauri-vue-template.git
```

Clone the Turborepo template:

```bash
git clone -b turborepo https://github.com/zzjtnb/tauri-vue-template.git
```

If a branch does not exist yet, that template variant has not been published.

## Branches

- `main`: Repository entry point, branch directory, and shared notes.
- `standalone`: Single-app template branch.
- `turborepo`: Turborepo template branch.
