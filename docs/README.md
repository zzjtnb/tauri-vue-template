# 文档索引

当前 standalone 模板只维护实际存在的仓库文档，不保留空的功能文档或 AI 记录目录约定。

## 仓库规则

| 路径 | 说明 |
| --- | --- |
| `docs/模块化编码规则.md` | 模块职责、公共 API、状态、扩展、文档和验证规则。 |

## Tauri 文档

| 路径 | 说明 |
| --- | --- |
| `docs/tauri/dev.md` | Tauri 项目重建、权限、开发流程说明。 |
| `docs/tauri/cli/` | Tauri CLI 常用命令说明。 |
| `docs/tauri/guide/` | 桌面端、移动端、OpenHarmony、配置、签名与依赖更新指南。 |

## 维护规则

- 新文档必须放到实际存在的目录中，不新增空目录约定。
- 文档示例必须使用当前模板真实脚本、真实路径和真实配置。
- 如果新增目录或稳定文档入口，同步更新本索引和根 `README.md`。
- 文档变更后至少执行 `pnpm lint:markdownlint` 验证格式和链接范围。
